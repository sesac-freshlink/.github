# common v0.4.0: 보낸 줄·처리 기록 자동 정리

> 담당: 김진아 · 갱신: 2026-10-30 · 상태: 현재 · 태그: v0.4.0 (2026-10-29)

## 1. 한 줄 요약

다 보낸 `outbox` 행과 오래된 `processed_message` 행을 1시간마다 자동으로 지우는 `MessageCleaner`를 더했다.

## 2. 왜 필요했나

Outbox와 멱등 표는 쪽지가 오갈 때마다 한 줄씩 늘어나기만 한다. 지우지 않으면 표가 계속 커지고, 발행기가 안 보낸 행을 찾는 조회도 점점 느려진다.

## 3. 바뀐 것

| 지우는 것 | 기준 (기본값) |
| --- | --- |
| `outbox` | 보낸 지(`published = TRUE`) 7일 넘은 행. 안 보낸 행은 지우지 않는다 |
| `processed_message` | 30일 넘은 행 |

- 1시간마다, 1000개씩 나눠 지운다.
- ShedLock 잠금 `freshlink-message-cleanup`으로 한 파드만 지운다. 발행기 잠금과 이름이 달라서 지우는 동안에도 발행은 계속된다.
- 설정 `freshlink.messaging.cleanup.*` (`enabled`, `interval`, `outbox-retention`, `processed-retention`, `batch-size`)

## 4. 쓰는 서비스가 할 일

버전만 올리면 된다. 기본값으로 켜지고 **표 변경·Flyway 파일은 없다.**

## 5. 배포 순서와 주의할 점

- 순서 상관없다.
- `processed-retention`은 **18일(SQS 본 큐 4일 + DLQ 14일)보다 길어야 한다.** 짧으면 DLQ에서 다시 넣은 쪽지의 처리 기록이 이미 지워져서 두 번 반영된다.
