## 1. 그룹(바깥 → 안)

| 그룹 | 스타일 | 들어가는 것 |
| --- | --- | --- |
| AWS 바깥 (왼쪽) | 테두리 없음 | 사용자(점주 포스기·고객 핸드폰), GitHub(앱 레포 5개, GitHub Actions, `gitops` 레포) |
| AWS 바깥 (오른쪽) | 테두리 없음 | 토스페이먼츠 (테스트 결제 API) |
| AWS Cloud | 검은 실선 + AWS 로고 | 아래 전부 |
| 글로벌/리전 관리형 (VPC 밖, 왼쪽 열) | 아이콘만 | CloudFront(+ACM), S3(비공개, OAC), ECR(리포 5개), IAM(OIDC·IRSA) |
| Region 서울 ap-northeast-2 | 파란 실선 + 깃발 | VPC, SQS |
| VPC 10.0.0.0/16 | 초록 실선 | IGW(왼쪽 경계), AZ 2개 |
| AZ ap-northeast-2a / 2c | 하늘색 점선, 위·아래 두 줄 | 서브넷 3계층 |
| public-a / public-c | 연두 배경 | ALB 노드, NAT Gateway(2a에만 1개) |
| app-a / app-c (private) | 하늘 배경 | EKS 노드 (t3.large) |
| db-a / db-c (private) | 하늘 배경 | RDS MySQL 기본(2a), 대기 자리(2c, 다중 AZ 시) |
| EKS Cluster | 주황 점선, 두 AZ의 app 서브넷에 걸침 | 노드1: gateway#1·inventory#1·order#1·member#1·ArgoCD / 노드2: gateway#2·inventory#2·order#2·simulator·LB Controller |
| SQS (VPC 밖, 리전 안 오른쪽) | 분홍 아이콘 | `inventory-commands.fifo`(그룹=점포), `inventory-results`(표준), DLQ 2개 |

## 2. 화살표(번호 = 배지)

1. 사용자 → CloudFront (HTTPS, 한 주소)
2. CloudFront → S3: `/` 화면 (OAC)
3. CloudFront → IGW → ALB: `/api/*`
4. ALB → gateway 파드 (target type `ip`, 두 AZ)
5. gateway → member / inventory / order (JWT 검증 후 라우팅, 노드 안 표기)
6. 서비스 파드 ↔ RDS MySQL (서비스별 스키마)
7. simulator·order → `inventory-commands.fifo` → inventory → `inventory-results` → order, 실패 3번 → DLQ (IRSA로 권한 분리)
8. order → NAT → IGW → 토스페이먼츠 (결제 승인)
9. GitHub Actions → ECR (OIDC로 IAM Role, 이미지 푸시)
10. GitHub Actions → `gitops` 레포 (이미지 태그 커밋)
11. ArgoCD ← `gitops` 레포 (pull, 동기화) / 노드 ← ECR (이미지 pull)
12. GitHub Actions → S3 업로드 + CloudFront 무효화 (프론트 배포)
13. Loki → S3 로그 버킷 (IRSA)
14. EventBridge Scheduler → RDS 중지·시작, 노드 그룹 0↔2
15. 사용자 → Amazon Cognito (가입·로그인, JWT 발급). Region 안·VPC 밖 오른쪽 위에 둔다. gateway는 Cognito 공개 키(JWKS)로 검증 (5번)

실선 = 사용자 요청 경로, 점선 = 비동기 메시지·배포 경로.

## 3. 배치

- 가로 1700 × 세로 1100. 왼쪽 열(사용자·GitHub) → AWS 관리형 열 → VPC → SQS 열 → 토스 순으로 왼쪽에서 오른쪽 흐름.
- VPC 안은 예시처럼 AZ 2a를 위, 2c를 아래 줄에 두고, 두 AZ 사이 띠에 IGW·ALB·EKS 클러스터 라벨·SQS 연결선을 둔다.
- 서브넷 열 순서: public → app → db (왼쪽에서 오른쪽).
- 색: 네트워킹 보라, 컴퓨팅·컨테이너 주황, 스토리지 초록, DB 파랑, 앱 통합 분홍, 보안 빨강 (AWS 아이콘 색 체계).
