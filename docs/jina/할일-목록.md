## 지키는 규칙

- 앞 번호가 끝나야 뒤 번호를 시작한다. 같은 날 인프라 세션(`infra`·`gitops`·`.github` 폴더)과 백엔드 세션(`common`·`gateway`·`logistics-simulator` 폴더)을 동시에 열어 두 줄로 진행한다.
- 에이전트는 `terraform apply`·`destroy`, `kubectl apply`, AWS 리소스 변경을 하지 않는다. plan을 보고 **내가 직접 apply**한다.
- 커밋은 내가 말할 때만 한다. 팀원 레포는 PR로만 올린다.
- 개발은 AWS dev 환경에서 한다. prod는 릴리스 확인·리허설·시연 날만 켠다.
- dev 클러스터는 매주 금요일 21:00에 자동 삭제된다. 금요일 작업은 그 전에 끝낸다.
- 비밀값(DB 비밀번호, 토스 키, 토큰)은 문서·코드·채팅에 쓰지 않는다. Secrets Manager에만 둔다.
