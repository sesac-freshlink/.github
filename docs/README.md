## 문서 관리 규칙

1. **목차는 이 파일 하나다.** 문서를 더하거나 옮기거나 상태가 바뀌면 같은 PR에서 이 표를 고친다.
2. **폴더는 "무엇을 하려고 여나"로 고른다.** 결정과 이유는 `기획/`, 모두 지킬 것은 `규칙/`, 따라 하는 사용법은 `팀원-가이드/`, 기능 흐름 설명은 `기능이해/`, 넘겨주는 작업 메모는 `인수인계/`, 할 일은 `할일/`.
3. **끝난 문서는 옮기지 않는다.** 상태만 `완료`로 바꾼다. 옮기면 다른 레포의 링크가 깨진다.
4. **새 문서나 크게 고친 문서는 맨 위에 한 줄을 둔다.** 예: `> 담당: 김진아 · 갱신: 2026-10-30 · 상태: 현재`
5. **이름은 한글 낱말을 `-`로 잇는다.** 띄어쓰기는 쓰지 않는다(링크에 `%20`이 생긴다). 그림은 같은 폴더의 `images/`에 둔다.
6. **링크.** 이 레포 안에서는 상대 경로로 건다. 다른 레포에서는 `https://github.com/sesac-freshlink/.github/blob/main/docs/...` 전체 주소로 건다.
7. **옮기거나 이름을 바꿀 때는** 10개 레포 전체에서 옛 경로를 검색해 같이 고친다. 다른 레포 CLAUDE.md·README와 코드 주석(`GlobalExceptionHandler.java`, `MessageType.java`, `orderStatus.ts`, infra `*.tf`)에도 경로가 적혀 있다.
